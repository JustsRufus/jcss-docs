Pourquoi JCSS ?

JCSS est un DSL (Domain-Specific Language) qui supprime la double écriture HTML/CSS. Vous écrivez du style structuré, le moteur génère des pages web complètes, valides et prêtes à l'emploi. Fini la dissociation entre la structure et l'apparence visuelle.

🎯 Productivité accrue

Pas besoin de jongler entre fichiers .html et .css. Une seule source de vérité, une seule syntaxe.

🧠 Ergonomie cognitive

Réduit la charge mentale grâce à l'imbrication naturelle et aux règles unifiées.

⚡ Génération rapide

Mode watch intégré : modifiez votre fichier .jcss, le HTML/CSS/JS est regénéré instantanément.

🌐 100% standards web

Sortie HTML5, CSS3 et JavaScript valides. Compatible avec tout navigateur moderne.

📦 Installation

Prérequis : Node.js (n'importe quelle version récente).
Plateforme : Windows ✅ · macOS (bientôt) · Linux (bientôt) 
npm install -g @rufus_lokuma/jcss

Vérifiez l'installation :

jcss -v

JCSS fonctionne immédiatement sans fichier de configuration initiale. Créez un dossier pour votre projet :

mkdir mon-app-jcss
cd mon-app-jcss
jcss init

La commande jcss init génère l'arborescence suivante :

mon-app-jcss/
├── index.jcss              # point d'entrée principal
├── modules/
│   ├── README
│   ├── app/                # (créé à la compilation) fichiers HTML/CSS/JS générés
│   └── resources/
│       ├── fonts/
│       ├── imports/        # autres fichiers .jcss à importer
│       ├── medias/
│       └── external/       # fichiers HTML, CSS, JS externes
└── path.config             # configuration interne

Si le projet existe déjà, jcss init exécute immédiatement le code présent dans index.jcss.

🧩 Directives JCSS

Les blocs sont introduits par @ suivi du type de directive. Le moteur reconnaît 7 formes principales.

1. Directive initiale (obligatoire)

@drc("jcss")              // langue par défaut
@drc("jcss", "fr")        // avec spécification de langue

2. @page — création de page HTML

@page(accueil){
    body{
        background: #f4f4f4;
        & .container {
            text: "Bienvenue sur JCSS";
            dimension: 100% 80vh;
            axe: center center;
        }
    }
}

Génère une page HTML complète avec structure DOM et styles intégrés. Le sélecteur & indique l'imbrication.

3. @style — feuille de style externe

@style(main){
    .btn {
        background: #2e6b3e;
        padding: 0.5rem 1rem;
    }
}

4. @script — code JavaScript

@script(app){
    console.log("JCSS est prêt !");
    document.querySelector('h1').style.opacity = '1';
}

5. @meta — insertion dans le <head>

@meta(page1){
    <link href="https://cdn.tailwindcss.com" rel="stylesheet">
}

6. @function — blocs réutilisables

@function(theme){
    color: #1e2c3a;
    font-family: 'Inter';
}

body{
    function: theme;
}

7. @import — modularité

@import("./modules/resources/imports/pages.jcss")

✨ Extensions CSS uniques

PropriétéDescriptionExemple
textInjecte du contenu textuel dans l'élémenttext: "Hello JCSS";
dimensionRaccourci pour width + heightdimension: 100% 80vh;
axeAlignement flex/grid (center start / center center)axe: center center;
functionApplique un bloc de style réutilisablefunction: fonts_settings;

⚙️ Workflow quotidien

JCSS intègre un watcher en temps réel. Aucune commande manuelle à répéter : sauvegardez votre fichier .jcss, la régénération est automatique.

jcss init        # lancement du watcher + compilation initiale

En cas d’erreur, des messages clairs s’affichent dans le terminal avec localisation et suggestion de correction. Si l’erreur n’est pas encore gérée, le watcher attend la correction.

Intégration VS Code : extension disponible (surlignage syntaxique, snippets).

modules/app/

Chaque @page génère un fichier HTML distinct.

🚀 Exemple complet : Landing page

Créez un fichier index.jcss et collez ce code. Lancez jcss init et observez la magie.

@drc("jcss")

@page(landing){
    html{
        background: #fefefe;
        & body {
            font-family: 'Inter', system-ui;
            margin: 0;
            padding: 2rem;
        }
        & .hero {
            dimension: 100% 90vh;
            axe: center center;
            text-align: center;
            & h1 {
                text: "Bienvenue sur JCSS";
                font-size: 3rem;
                color: #2e6b3e;
            }
            & p {
                text: "Générez vos pages web sans écrire HTML.";
                font-size: 1.2rem;
                margin-top: 1rem;
            }
            & button {
                background: #2e6b3e;
                border: none;
                color: white;
                padding: 0.75rem 1.8rem;
                border-radius: 40px;
                text: "Commencer";
                font-weight: bold;
                margin-top: 2rem;
                cursor: pointer;
            }
        }
    }
}

@style(main){
    button:hover {
        background: #1f4a2c;
        transform: scale(1.02);
    }
}

@script(app){
    const btn = document.querySelector('button');
    if(btn){
        btn.addEventListener('click', () => {
            alert('JCSS en action ! 🚀');
        });
    }
}

Résultat : une page HTML complète avec styles imbriqués, contenu texte, et interaction JavaScript — sans jamais écrire une balise HTML manuellement.

🔁 Exemple multi-pages

@drc("jcss")

@page([home, Index]){
    body{
        background: white;
        & nav { ... }
        & .card { ... }
    }
}

@page([contact, Contact Us], style.css){
    body{
        background: #eef2ff;
        & form { ... }
    }
}

Génère deux fichiers HTML : home.html et contact.html.

🎯 Quand utiliser JCSS ?

✅ Idéal pour :

  • Prototypage rapide d’interfaces
  • Projets frontend sans backend lourd
  • Développeurs débutants voulant réduire la courbe d’apprentissage
  • Applications web simples à moyennes

⚠️ Moins adapté pour :

  • Projets colossaux avec architecture très spécifique
  • Environnements où l’on ne peut pas installer Node.js
  • Frameworks complexes (Angular, Laravel) sans intégration directe

📈 Roadmap & évolutions

  • ✔️ Support macOS / Linux (prévu prochainement)
  • ✔️ Variables CSS natives et conditions
  • ✔️ Gestion des erreurs complète et messages ultra-clairs
  • ✔️ Écosystème : extension VS Code enrichie, documentation interactive
  • ✔️ Évolution vers un langage fullstack lisible par navigateur

🧑‍💻 Expérience utilisateur

JCSS a été pensé pour une prise en main ultra-rapide. La syntaxe reprend les bases du CSS, et l'imbrication reflète naturellement la hiérarchie du DOM. La plupart des développeurs se sentent opérationnels en moins d'une heure.

Feedback initial : “La directive @page élimine le besoin d'écrire des squelettes HTML, c'est libérateur.” — “Les propriétés comme dimension et axe accélèrent le layout moderne.”

💡 Bon à savoir : vous pouvez intégrer n’importe quelle bibliothèque CSS (Bootstrap, Tailwind) via @meta et utiliser les classes avec le sélecteur d’attribut en JCSS.
