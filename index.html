JCSS
Just Coding with Stylesheet Structure

Un DSL orienté style qui génère automatiquement du HTML, CSS et JavaScript à partir d’une syntaxe unique. Supprimez l’écriture manuelle du HTML, accélérez le développement front-end.

Présentation générale

JCSS est un DSL qui réinvente le workflow front-end en faisant du style le point d'entrée unique.

Unification structure & style

Plus de double écriture HTML/CSS. Vous décrivez l'interface avec une syntaxe proche du CSS, le moteur génère le HTML, le CSS et le JavaScript conformes aux standards W3C.

Productivité accrue

Réduit la redondance et la charge cognitive. Idéal pour le prototypage rapide et les projets front-end de taille modérée.

100% compatible

Génère du HTML/CSS standard. Utilisable avec n'importe quel serveur web, et extensible avec des bibliothèques comme Tailwind ou Bootstrap via la directive @meta.

Syntaxe inspirée du CSS

Imbrication naturelle, sélecteurs, propriétés additionnelles comme text, dimension ou axe pour une ergonomie maximale.

Différences clés

  • CSS → nécessite du HTML préalable ; JCSS génère HTML automatiquement.
  • Tailwind → travaille sur une structure HTML existante ; JCSS supprime l’écriture manuelle du HTML.
  • Sass/Less → enrichissent CSS mais ne génèrent pas de structure ; JCSS produit des pages entières.

Installation

Prérequis : Node.js (version récente). Actuellement supporté sur Windows (macOS et Linux en roadmap).

 npm install -g @rufus_lokuma/jcss

Vérifiez l'installation :

jcss -v

Pas de fichier de configuration initiale requis. L'installation globale permet d'utiliser la commande jcss dans votre terminal.

Info : Bientôt disponible sur macOS et Linux. Restez connectés !

Premier projet

Initialisez une nouvelle application JCSS en une commande.

mkdir mon-projet && cd mon-projet
jcss init

Cette commande génère la structure suivante :

mon-projet/
├── index.jcss          # point d'entrée principal
└── modules/
    ├── README
    ├── app/            # fichiers générés (HTML, CSS, JS)
    └── resources/
        ├── fonts/
        ├── imports/    # autres fichiers .jcss
        ├── medias/
        └── external/
            ├── css/    # styles externes
            ├── js/     # scripts externes
            └── *.html

Le fichier index.jcss est le cœur de votre application. Lancez la compilation avec :

jcss init   # exécute directement le code JCSS et lance le mode watch

Le moteur détecte les modifications et recompile automatiquement.

Syntaxe & directives

JCSS utilise des blocs spécifiques introduits par @. Les 7 directives fondamentales :

@drc @page @style @script @meta @function @import

@drc — Directive initiale

Obligatoire, indique que le code est du JCSS et définit la langue (optionnelle). Exemple : @drc("jcss", "fr").

@page — Création de page

Génère une page HTML complète. Supporte l’imbrication CSS et le texte direct avec la propriété text.

@style / @script

Injectent des feuilles de style ou scripts JavaScript dans les pages générées.

@meta — Éléments d’en‑tête

Ajoute du contenu dans le <head> (link, meta, etc.) via un nom de référence.

@function — Fonctions réutilisables

Définit des blocs de propriétés CSS réutilisables appelés via function: nom;.

@import — Modularité

Importe d’autres fichiers .jcss depuis resources/imports.

Extensions CSS natives

text: "contenu" — injecte du texte dans l’élément.
dimension: 100% 50% — width + height.
axe: center start — combine align & justify.
function: nom — applique un bloc @function.

Workflow développeur

Mode watch automatique

Lorsque vous lancez jcss init, le moteur reste actif et recompile à chaque modification du fichier index.jcss ou des imports. Les erreurs s’affichent dans la console avec des indications claires.

Gestion des erreurs

Messages explicites avec localisation et suggestions de correction. En mode session interactive, le programme ne s’arrête pas, il attend la correction.

Intégration VS Code

Extension disponible (syntax highlighting). Le terminal intégré permet de lancer la compilation sans quitter l’éditeur.

Performance

Moteur rapide, pipeline de transformation déterministe. Idéal pour des itérations rapides.

Exemple concret

Une page d’accueil simple avec titre, conteneur et message dynamique.

@drc("jcss")

@function(primaryStyle){
    color: #1d1d1f;
    font-family: 'Inter', sans-serif;
    font-size: 1.125rem;
}

@page(home){
    body{
        function: primaryStyle;
        background: #f5f5f7;
        margin: 0;
        & .hero{
            dimension: 100% 100vh;
            axe: center center;
            display: flex;
            flex-direction: column;
            & h1{
                text: "Bienvenue sur JCSS";
                font-size: 3rem;
                font-weight: 600;
                margin-bottom: 1rem;
            }
            & p{
                text: "Génération HTML/CSS automatique — zéro redondance.";
                font-size: 1.25rem;
                color: #6e6e73;
            }
            & button{
                text: "Explorer";
                background: #1d1d1f;
                color: white;
                border: none;
                padding: 0.75rem 1.5rem;
                border-radius: 48px;
                margin-top: 2rem;
                cursor: pointer;
            }
        }
    }
}

@script(main){
    document.querySelector('button')?.addEventListener('click', () => {
        alert('JCSS en action !');
    });
}

Le fichier index.jcss ci-dessus génère une page home.html dans modules/app/ avec le style et le comportement JavaScript associés. Aucun HTML écrit manuellement.

Résultat CSS attendu (extrait)

body { color: #1d1d1f; font-family: 'Inter', sans-serif; background: #f5f5f7; margin: 0; }
.hero { width: 100%; height: 100vh; display: flex; align-items: center; justify-content: center; flex-direction: column; }
.hero h1::before { content: "Bienvenue sur JCSS"; }

État actuel & roadmap

Limitations actuelles

  • Pas de variables CSS natives (prévues)
  • Support limité aux sélecteurs complexes (classes, IDs avancés en cours)
  • Compatibilité macOS/Linux en développement
  • Frameworks backend non intégrés directement, mais fichiers générés utilisables

Feuille de route

  • Conditions et boucles dans le langage
  • Support multi-OS complet
  • Amélioration du système d’erreurs (100% couvert)
  • Évolution vers un langage full-stack lisible par navigateur
  • Variables et mixins avancés

Expérience utilisateur

Apprentissage très rapide (~1h pour être opérationnel). Syntaxe familière pour les développeurs CSS. La courbe d’adoption est douce grâce à l’unification structure/style et aux retours explicites du compilateur.

Cas d’usage

Idéal pour

Prototypage rapide, projets front-end indépendants, développeurs débutants souhaitant éviter la complexité HTML/CSS, équipes cherchant à réduire la dette de style.

À éviter pour

Applications très complexes avec architecture backend lourd, si vous avez besoin de contrôle granulaire sur chaque balise HTML, ou dans des environnements sans Node.js.

Intégration dans des projets existants

Vous pouvez utiliser JCSS pour générer les pages puis les récupérer depuis le dossier modules/app pour les intégrer dans Laravel, React ou tout autre framework. Le CSS/JS généré est standard et immédiatement exploitable.
